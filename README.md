A program that writes one original micro-confession — a To: line naming who it was meant for, and the unsent message itself, exactly as it was once typed and never sent — to `entry.txt`, for make.fun's "Unsent: The Micro-Confession Sprint" bounty.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=/tmp/unsent-out python3 main.py
```
